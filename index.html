vibed-tools

A collection of browser-based interactive tools — no install required.

Tool Category Description
Knowledge Tree Learning Gamified flashcard and quiz system for memorising hierarchical knowledge. Supports custom categories, fuzzy-match answer checking, mastery tracking, images, and GBIF species lookup. Data is stored locally in the browser and can be imported/exported as JSON.
HTML Viewer & Formatter Developer Paste, drop, or open HTML files to instantly beautify, minify, and preview them. Features syntax-highlighted editing (CodeMirror), live preview, DOM tree inspector, and basic validation — all offline with no ads.
Markdown Table → Excel Productivity Paste a markdown table and copy it straight into Excel with formatting intact. Bold, italic, code, strikethrough and links are preserved, <br> becomes an in-cell line break, and prose outside tables is dropped. Pick exactly which cells to copy from an Excel-like selectable grid — all offline, no build step.
NetCDF Climate Viewer Science Drag-and-drop viewer for NetCDF Classic (v3) climate files. Renders gridded data on an interactive Leaflet map with a customisable colour scale, supports time-series plots via Plotly, and lets you slice across any dimension (time, latitude, longitude) directly in the browser — no server needed.
